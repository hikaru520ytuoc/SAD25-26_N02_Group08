# Evidence provenance

- `reference-logs/`: saved output from an earlier execution of the independent C coursework project; these are **not** logs of this GitHub repo's backend or frontend.
- `images-from-logs/`: visually formatted exports recreated from these earlier logs, **not actual screenshot captures** from the instructor's Windows `SecLabFramework.exe` GUI.
- `../results/`: fresh runtime logs created when YOU run `bash scripts/run_pipeline.sh` on your own computer; those logs are excluded from Git by `.gitignore`.

Report numerical results only after reproducing locally. ASan stacks, execution timing and coverage may change by machine/compiler.
